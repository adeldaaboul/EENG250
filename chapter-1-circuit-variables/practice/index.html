S1Prefixes
A sensor’s output current is 0.000047 A. Which is the way engineers write it, with the prefix chosen so the number lies between 1 and 1000?

Answer

$0.000047$ A $= 47 \times 10^{-6}$ A $= 47$ µA. (a) has the same value but not the preferred prefix, since 0.047 is below 1. (d) is $4.7 \times 10^{-8}$ A, a thousand times too small.

Your home has a 5 A generator subscription at 220 V. Treat each rating as the power the appliance draws: kettle 2000 W, washing machine 500 W, heater fan 300 W, fridge 150 W, TV 100 W, laptop 65 W, all LED lights together 60 W. Which set can run at the same time without tripping the breaker?

Answer

Reason

The limit is power at any moment: $P = VI = 220 \times 5 = 1100$ W. The sets draw (a) 2060 W, (b) 1175 W, (c) 875 W and (d) 2000 W, so only (c) fits. The kWh meter counts energy; the ampere size limits power.
S3Charge from a current graphPredict first
The graph shows the current entering an element (zero outside the times shown).

Predict first: is the total charge more or less than 4 mA × 6 s = 24 mC?

How much charge enters the element in total?

Charge is the area under $i(t)$: $\tfrac12(2)(4) + (3)(4) + \tfrac12(1)(4) = 4 + 12 + 2 = 18$ mC. It is less than 24 mC because the current is below 4 mA during the ramps.
S4Current from chargeTwo-tier
The charge entering an element is $q(t) = 4(1 - e^{-250t})$ mC for $t \ge 0$, and zero before. What is the current at $t = 0^+$?

Answer

Reason

$i = dq/dt = (4 \times 10^{-3})(250)\,e^{-250t} = e^{-250t}$ A, so $i(0^+) = 1$ A. Reason (i) confuses the charge at $t = 0$ with the current at $t = 0$: the charge is zero but it is rising fastest.

S6What a negative voltage means
Which statement is true?

Answer

The + mark is at b, so $v = v_b - v_a = -12$ V. Then $v_a - v_b = +12$ V: terminal a is 12 V higher. Without a current you cannot say anything about power, so (d) is not justified.

Four elements are connected between the same two wires. Their reference values are:
ElementABCD
$v$ (V)12−12−1212
$i$ (A)3−5−42

Predict first, with no numbers: for which elements does the reference arrow enter the + terminal?

Which elements absorb power?

Total power delivered

The arrow enters + for A (+ at the top, arrow down) and C (+ at the bottom, arrow up). So $p_A = vi = 36$ W, $p_B = -vi = -60$ W, $p_C = vi = 48$ W, $p_D = -vi = -24$ W. A and C absorb. Delivered $60 + 24 = 84$ W equals absorbed $36 + 48 = 84$ W, so the four powers add up to zero.

S9Same element, different arrowsTwo-tier
Student X draws the current arrow into the + terminal of an element and finds $v = 5$ V, $i = 2$ A. Student Y analyses the same element but draws the current arrow the other way, keeping the same voltage polarity. What does Y get?

Answer

Reason

Y’s arrow enters the − terminal, so Y reads $i = -2$ A and uses $p = -vi = -(5)(-2) = 10$ W, absorbed: the same as X. Reference directions are bookkeeping; the physics cannot depend on how you draw them.
S10Charging a battery
A 12 V car battery is charged at a constant 5 A for 2 h. How much energy is delivered to the battery?

Answer

Follow-up: the same energy in kWh

Follow-up: while charging, the charger current enters the battery’s…

$w = vit = 12 \times 5 \times 7200$ s $= 432$ kJ $= 0.12$ kWh. (a) used hours instead of seconds; (b) used minutes. While charging, the battery absorbs power, so the current enters its + terminal.
S11Your power bankTwo-tier
A power bank is rated 10,000 mAh at 3.7 V. It charges a phone through a 5 V, 3 A output. Ignoring losses, how long can it supply that output?

Answer

Reason

Stored energy: $10$ Ah $\times 3.7$ V $= 37$ Wh. Output power: $5 \times 3 = 15$ W. Time: $37 / 15 \approx 2.5$ h. (a) treats mAh as energy; (d) divides Wh by A, which does not give hours.
S12Energy from time-varying power
For $t \ge 0$, an element has $v = 50e^{-200t}$ V and $i = 4e^{-200t}$ A, with the current entering the + terminal. What total energy is delivered to the element from $t = 0$ to $\infty$?

Hint: First write $p(t)$. How fast does $p$ decay compared with $v$ and $i$?

Answer

$p = vi = 200e^{-400t}$ W, so $w = \int_0^\infty 200e^{-400t}\,dt = 200/400 = 0.5$ J. (b) keeps 200 in the exponent instead of 400.
S13Power balanceTwo-tier
A circuit has five elements. Using the passive sign convention, four of the powers are $p_1 = -60$ W, $p_2 = +25$ W, $p_3 = +18$ W and $p_4 = -8$ W. What is $p_5$?

Answer

Reason

$-60 + 25 + 18 - 8 + p_5 = 0$, so $p_5 = +25$ W, absorbed. (a) drops the sign of $p_4$.
S14Spot the errorSpot the error
The worked solution below contains the kind of mistake AI chat tools most often make on circuit diagrams.
  1. The 3 A source drives a clockwise current of 3 A through elements 1 and 2.
  2. Element 1: $p_1 = (9)(3) = 27$ W, absorbed.
  3. Element 2: the current enters the + terminal, so $p_2 = (15)(3) = 45$ W, absorbed.
  4. KVL clockwise, drops positive: $-V - 9 + 15 = 0$, so $V = 6$ V.
  5. Source: the current leaves its + terminal, so $p_s = -(6)(3) = -18$ W, delivered.
  6. All powers have been found, so the solution is complete.

a) Which is the first wrong line?

b) The corrected value of $p_1$

c) With the corrected values, the total power delivered

d) Which line should have made you distrust this solution?

The clockwise current enters element 1 at its − terminal, so $p_1 = -(9)(3) = -27$ W: element 1 delivers. Balance: delivered $27 + 18 = 45$ W equals absorbed 45 W. Line 6 claims the solution is complete without a power balance; doing one would have shown $27 + 45 \ne 18$.
S15Work backwards
The current arrow of an element enters its + terminal and $i = 2$ A. What must $v$ be for the element to deliver 30 W?

Answer

Delivering 30 W means $p = vi = -30$ W, so $v = -30/2 = -15$ V.
S16When does circuit theory apply?
Use $\lambda = c/f$ with $c = 3 \times 10^8$ m/s and the one-tenth rule. Which systems can be analysed as lumped circuits?
(i) a 30 km distribution feeder at 50 Hz   (ii) a 10 cm Wi-Fi board at 2.4 GHz   (iii) a 20 cm audio amplifier at 20 kHz

Answer

50 Hz: $\lambda = 6000$ km, limit 600 km, so 30 km is fine. 2.4 GHz: $\lambda = 12.5$ cm, limit 1.25 cm, so 10 cm fails. 20 kHz: $\lambda = 15$ km, limit 1.5 km, so 20 cm is fine.
