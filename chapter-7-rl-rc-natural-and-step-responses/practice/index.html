This sheet is not marked for correctness, and AI tools are allowed. The device-free quiz, at the start of the last class (week 13, session 2, Thu 14 Jan), is built from twins of these questions, so make sure you can do each one on your own.

  • Two-tier items ask for an answer and a reason. Get both right; on the quiz each earns half the marks.
  • Predict first: where asked, make your prediction before you calculate.
  • Confidence: mark each question Sure or Unsure. It is not marked; it shows you what to revise.
  • Conventions: “a long time” means the circuit has reached dc steady state: an inductor is a short circuit and a capacitor an open circuit. Every response here has the form $x(t) = x_f + (x_0 - x_f)e^{-t/\tau}$, with $\tau = L/R$ or $\tau = RC$, where $R$ is the resistance the inductor or capacitor sees after switching. Check every answer: $x(0)$ must equal the initial value, $x(\infty)$ the final value, and $\tau$ must be positive.
  • Entering numbers: type each value in the unit shown next to its box (for example, 50 for 50 ms), with a minus sign where needed.

S14An artificial pacemakerPredict first
As in Nilsson’s Practical Perspective for this chapter. A source $V_s$ charges a capacitor $C$ through a resistor $R$, starting from 0 V. When $v_C$ reaches $0.75V_s$, a controller discharges the capacitor in a negligible time and sends a pulse to the heart; then charging starts again.

a) Show that each charging takes $t = RC\ln 4$, so the heart rate is $H = 60/(RC\ln 4)$ beats per minute.

Show it on paper, then compare with the explanation.

b) With $C = 2$ µF, what $R$ gives 60 beats per minute?

c) With $C = 2$ µF and $R = 300$ kΩ, what is the heart rate?

d) Predict first: what happens to the heart rate if $R$ is doubled?

a) $V_s(1 - e^{-t/RC}) = 0.75V_s$ gives $e^{-t/RC} = 0.25$, so $t = RC\ln 4$, and $H = 60/t$. b) $H = 60$ needs $t = 1$ s: $RC = 1/\ln 4 = 0.721$ s, so $R = 0.721\text{ s}/2\ \mu\text{F} = 361$ kΩ. c) $RC = 0.6$ s: $H = 60/(0.6\ln 4) = 72.1$ beats per minute. d) It halves: doubling $R$ doubles $RC$ and so the time of each charging.
